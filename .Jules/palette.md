## 2026-09-29 - Pine Script Indicator Settings Quick Toggle Tooltips and Titles
**Learning:** In TradingView Pine Script indicators, settings input controls serve as the primary user interface. When module quick toggles lack structured tooltips or standard module prefixes (e.g. `M3`), users lack clarity on timeframe requirements, role, reason, and expected output.
**Action:** Ensure all module master switches in Quick Toggles feature uniform module prefix labeling (`M<N> <Name>`) and structured tooltips specifying TIMEFRAME, ROLE, REASON, and END GOAL.
